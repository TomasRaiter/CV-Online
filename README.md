# Portfolio · Tomás Raiter

Sitio web personal hecho con HTML, CSS y un poco de JavaScript. No necesita instalar nada.

## Páginas

- `index.html`: perfil, estudios y habilidades
- `proyectos.html`: To The Top y Casino, con links a sus repositorios
- `contacto.html`: mail, teléfono y GitHub

## Cómo verlo

Abrí `index.html` en el navegador.

## Cómo publicarlo (GitHub Pages)

1. En el repositorio: Settings → Pages.
2. En "Branch" elegí `main` y la carpeta `/ (root)`.
3. Guardá y esperá un minuto: GitHub te da el link del sitio.

## Estructura

```
index.html
proyectos.html
contacto.html
css/styles.css
js/main.js
img/            ← acá van las capturas de los proyectos
```
